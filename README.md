# Dream11 Clone Project

## Overview

Dream11 Clone is a fantasy sports application that allows users to create their own teams and participate in various sports leagues. Users can select players, manage their teams, and compete for prizes based on real-world player performances.

## Features


- **Create and Manage Teams**: Users can create teams by selecting players from a given pool.
- **Join Leagues**: Users can join public and private leagues to compete with others.
- **Live Score Updates**: Real-time updates on player performances and league standings.
- **Leaderboard**: Track user rankings based on performance.


## Technologies Used

- **Frontend**: React.js
